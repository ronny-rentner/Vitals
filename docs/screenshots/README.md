# Screenshots

## Top bar

By default, the top bar shows memory usage, system load and download speed. For these screenshots, upload speed, average temperature and fan speed are pinned in addition.

| Setting | Result |
|---|---|
| Default settings | ![](top-bar.png)<br>![](top-bar-light.png) |
| **Emphasize values in top bar** disabled. When enabled, icons and units are drawn lighter and smaller than the numbers. | ![](top-bar-plain.png)<br>![](top-bar-plain-light.png) |
| **Icon style** set to GNOME. | ![](top-bar-gnome-icons.png)<br>![](top-bar-gnome-icons-light.png) |
| **Hide icons in top bar** enabled. Menu icons remain visible. | ![](top-bar-no-icons.png)<br>![](top-bar-no-icons-light.png) |
| **Use higher precision** enabled. Values have one more decimal place, and uptimes include seconds. | ![](top-bar-precision.png)<br>![](top-bar-precision-light.png) |
| Temperature **Unit** set to °F and network **Format** set to Bits. | ![](top-bar-fahrenheit-bits.png)<br>![](top-bar-fahrenheit-bits-light.png) |
| **Threshold Colors** defined for temperature and memory. A color applies from its threshold value up to the next one. | ![](top-bar-colors.png)<br>![](top-bar-colors-light.png) |

Each example is shown in the GNOME dark style and in the light style.

Any value in the menu can be pinned to the top bar. The following screenshots show four additional values: processor usage, free storage, voltage and uptime.

## Menu

Each category shows one value in its header. One category can be open at a time. Selecting a row opens a panel with its actions: pin it to the top bar, rename it, hide it, or make it the value the category shows in its header. The rest of the menu is dimmed while the panel is open.

The network category is shown with **Only show hardware interfaces** enabled, which is the default. It hides bridges, container, VPN and loopback interfaces.
